# HW2：遞迴方程式求解與複雜度分析

## 1. T(n) = T(n-1) + 8, T(1) = 1

### 求解（展開法）
```
T(n) = T(n-1) + 8
     = T(n-2) + 8 + 8
     = T(n-3) + 8 + 8 + 8
     = ...
     = T(1) + 8(n-1)
     = 1 + 8(n-1)
     = 8n - 7
```

### 精確解
**T(n) = 8n - 7**

### 複雜度
**O(n)** — 線性時間

---

## 2. T(n) = 2T(n-1) + 9, T(1) = 1

### 求解（展開法）
```
T(n) = 2T(n-1) + 9
     = 2[2T(n-2) + 9] + 9 = 4T(n-2) + 2·9 + 9
     = 4[2T(n-3) + 9] + 2·9 + 9 = 8T(n-3) + 4·9 + 2·9 + 9
     = ...
     = 2^(n-1)·T(1) + 9·Σ(i=0 to n-2) 2^i
     = 2^(n-1) + 9·(2^(n-1) - 1)
     = 2^(n-1) + 9·2^(n-1) - 9
     = 10·2^(n-1) - 9
     = 5·2^n - 9
```

### 驗證
- T(1) = 5·2^1 - 9 = 10 - 9 = 1 ✓
- T(2) = 5·2^2 - 9 = 20 - 9 = 11，而 2T(1)+9 = 2+9 = 11 ✓

### 精確解
**T(n) = 5·2^n - 9**

### 複雜度
**O(2^n)** — 指數時間

---

## 3. T(n) = 2T(n/2) + 1, T(1) = 1

### 求解（Master Theorem）
- a = 2, b = 2, f(n) = 1
- n^(log_b(a)) = n^(log_2(2)) = n^1 = n
- f(n) = 1 = O(n^(1-ε))，取 ε = 1 → **Case 1**
- T(n) = Θ(n)

### 精確解（假設 n = 2^k）
```
T(n) = 2T(n/2) + 1
     = 2[2T(n/4) + 1] + 1 = 4T(n/4) + 2 + 1
     = 4[2T(n/8) + 1] + 2 + 1 = 8T(n/8) + 4 + 2 + 1
     = ...
     = 2^k·T(1) + Σ(i=0 to k-1) 2^i
     = n·1 + (n - 1)
     = 2n - 1
```

### 驗證
- T(1) = 2·1 - 1 = 1 ✓
- T(2) = 2·2 - 1 = 3，而 2T(1)+1 = 2+1 = 3 ✓
- T(4) = 2·4 - 1 = 7，而 2T(2)+1 = 6+1 = 7 ✓

### 精確解
**T(n) = 2n - 1**（當 n 為 2 的冪次時）

### 複雜度
**O(n)** — 線性時間

---

## 4. T(n) = T(n/2) + 1, T(1) = 1

### 求解（Master Theorem）
- a = 1, b = 2, f(n) = 1
- n^(log_b(a)) = n^(log_2(1)) = n^0 = 1
- f(n) = 1 = Θ(1) = Θ(n^0) → **Case 2**
- T(n) = Θ(log n)

### 精確解（假設 n = 2^k）
```
T(n) = T(n/2) + 1
     = T(n/4) + 1 + 1
     = T(n/8) + 1 + 1 + 1
     = ...
     = T(1) + k
     = 1 + log₂(n)
```

### 驗證
- T(1) = 1 + log₂(1) = 1 + 0 = 1 ✓
- T(2) = 1 + log₂(2) = 1 + 1 = 2，而 T(1)+1 = 1+1 = 2 ✓
- T(4) = 1 + log₂(4) = 1 + 2 = 3，而 T(2)+1 = 2+1 = 3 ✓

### 精確解
**T(n) = log₂(n) + 1**（當 n 為 2 的冪次時）

### 複雜度
**O(log n)** — 對數時間

---

## 總結

| 遞迴式 | 精確解 | Big O |
|--------|--------|-------|
| T(n) = T(n-1) + 8 | 8n - 7 | O(n) |
| T(n) = 2T(n-1) + 9 | 5·2^n - 9 | O(2^n) |
| T(n) = 2T(n/2) + 1 | 2n - 1 | O(n) |
| T(n) = T(n/2) + 1 | log₂(n) + 1 | O(log n) |
