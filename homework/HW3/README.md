## 我對這支程式的理解

n 個變數就有 2ⁿ 種組合，所以我讓一個整數 `mask` 從 0 數到 2ⁿ − 1，
用它的第 i 個 bit 當作 xi 的值（例如 mask = 5 = 101₂ 就代表 x1=1, x2=0, x3=1），
這樣就等於把真值表一列一列列舉出來了，而且不會漏掉也不會重複。

**1. `compile_cnf(cnf)` — 先把公式編成位元**

把每個子句變成兩個 mask：`pos` 是子句裡正變數的位置，`neg` 是負變數的位置。
例如子句 (x1 ∨ ¬x2) 會編成 pos=001、neg=010。
先編一次，後面每一列就不用重複去解析子句了。

**2. `satisfied(compiled, mask)` — 檢查某一列是否成立**

一個子句被滿足，代表「至少有一個正變數是 1」或「至少有一個負變數是 0」，
寫成位元運算就是 `(mask & pos) != 0` 或 `(neg & ~mask) != 0`。
每個子句都過，這一列才是解；中途有一個子句不過就直接回 False，不用再檢查剩下的。

**3. `assignments(n)` — 系統性列舉**

就是 `for mask in range(2**n)`，從 000…0 走到 111…1，剛好是完整真值表的每一列。

**4. `solve(cnf, n)` — 找第一個解**

一列一列丟進 `satisfied()`，遇到第一個成立的就回傳那個 mask，
順便回傳「檢查到第幾列」和花了多少時間；全部列舉完都沒有，就是 UNSAT。

**5. `count_models(cnf, n)` — 算全部有幾個解**

跟 `solve()` 一樣的掃描，差別是它不會提前停，一定要掃完 2ⁿ 列才能把解的數目數完。
這也是為什麼 UNSAT 一定是最慢的：沒有東西可以讓它提早結束。

**6. `print_truth_table(cnf, n)` — 印出真值表**

把上面那些東西整理成表格印出來，變數欄是各 bit 的值，C 欄是每個子句的真假，F 欄是整體結果。
變數太多時（超過 64 列）就不印，不然會印到天荒地老。

**7. `parse_dimacs(text)` — 讀檔**

DIMACS 是 SAT 的標準輸入格式，`p cnf 3 3` 表示 3 個變數 3 個子句，
每行一個子句、用 0 結尾，負號代表 ¬。讀完就變回程式內部的 list 格式。
