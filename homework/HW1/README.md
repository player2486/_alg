# HW1：2^n 的四種寫法與效率比較（power2n.py）

對應 Issue #3，檔案：`power2n.py`，測試用 `n = 100`（也可以 `python power2n.py 1000` 自己指定 n）。

## 我對這支程式的理解

同一個 2ⁿ 有四種寫法，差別全在「怎麼重複」：直接呼叫內建運算子、遞迴呼叫兩次、
遞迴呼叫一次、以及遞迴加查表。四種都必須處理基本情形 `n == 0` 回傳 `1`，否則會無限遞迴。
主程式用 `bench()` 逐一測試四個函式，量測每次呼叫的耗時、自動決定重複次數，
並核對答案是否等於 `2**100`，把差異攤在同一張表上比。
時間複雜度排序：**方法 1 < 方法 2b < 方法 3 ≪ 方法 2a**（2b、3 都是 O(n)，但 3 有查表開銷）。
