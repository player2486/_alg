# TSP —— 演算法比較
`

**測試資料**：20 個城市，座標在 [0,100]×[0,100] 均勻隨機。固定亂數種子 42，每次執行資料都相同，五種方法面對同一個問題。

### 1. 貪婪演算法（最近鄰居）`greedy()`

- **做法**：從起點出發，每一步都走向最近的未訪問城市，走完回起點。
- **特性**：極快，但從不回頭修正，後期常被迫走長回頭路，品質最差。

### 2. 改良法（2-opt）`two_opt_improve()`

- **做法**：以貪婪解為起點，挑兩條邊並反轉中間一段，若變短就採用，直到無法再改善。
- **特性**：確定性、很快，能消除交叉邊，但會停在局部最佳。

### 3. 爬山演算法 `hill_climbing()`

- **做法**：隨機路徑出發，隨機交換兩個城市，變短才接受，重複 20000 次。
- **特性**：簡單，但一旦卡在局部最低點就出不來，結果很看運氣。

### 4. 模擬退火法 `simulated_annealing()`

- **做法**：同樣反轉一段路徑，但變差的解也會以機率 `exp(−Δ/T)` 接受；溫度 T 逐步降低，早期廣泛探索，後期精細收斂。
- **特性**：能逃離局部最佳、結果最穩定，但最慢（約 23 萬次迭代）。

### 5. 梯度下降法 `gradient_descent()`

- **做法**：把「第 k 步去城市 i」放寬成機率矩陣，用梯度優化（加懲罰項避免城市重複），最後解碼成合法路徑。
- **特性**：展示連續最佳化的做法，但損失函數非凸、超參數敏感，規模大時吃資源。
